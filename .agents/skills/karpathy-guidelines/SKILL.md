# Karpathy-inspired coding discipline

Read `AGENTS.md` at the repository root, especially **Karpathy-inspired coding
discipline**, and the standards applicable to the task. It is the canonical policy;
this skill introduces no separate rules, permission gates, roadmap or task status.

State material assumptions, choose the simplest solution within the authorized
scope, preserve unrelated work, and verify observable results with appropriate checks.
Continue already-authorized work; clarify only material unresolved decisions.

Graphify can help navigate those sources, but does not replace reading or verifying them.
